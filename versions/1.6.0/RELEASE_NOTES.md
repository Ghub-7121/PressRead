# 1.6.0 — 2026-10-31

> 查词终于默认给中文了；想要英文释义时再点一下，而且不点就不联网。

## 新增

- **查词默认英汉（剑桥英汉双解）**：点单词先给音标、词性、中文译词、英文原释义、例句对照，
  不再一上来全是英文。
  > 牛津官方的在线英汉（《牛津高阶英汉双解》第 10 版）必须登录授权才能取词条，
  > 程序抓不到；牛津学习者词典只有英英版。因此英汉改用同为三大学习者词典的剑桥英汉双解，界面如实标注。
- **英英按需加载**：词条右上角一个圆形 **EN** 钮，点了才去查牛津英英；不点则一个字节都不发。
- **译文语气三档**：自动 / 正式 / 非正式，按语气分别请求与缓存（`en>zh-CN|formal`），来回切换不互相覆盖。
  需要填 DeepL 的 API Key 才生效；没填时后两个按钮置灰并说明原因，不拿别的源冒充「正式译法」。

## 改进

- 中文释义与英文释义分开缓存（scope `zh` / `en`），先看哪种都不影响另一种。
- 义项最多渲染 12 个，超出提示去官网看，避免侧栏无限长。
- 翻译请求单源超时 9 秒且不重试，不通的源立刻让位；某源连续失败 2 次熔断 2 分钟，不再每句都卡超时。
- 翻译链路默认顺序：DeepL（填了 Key 才生效）→ MyMemory → Google。

## 兼容

- 缓存版本升到 2。老版本升级上来第一次启动会清空词典与译文缓存（因为换了词典源、加了语气档），
  练习记录、生词本、导出成果、历史文章都不动。
