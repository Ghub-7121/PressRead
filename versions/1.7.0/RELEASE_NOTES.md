# 1.7.0 — 2026-10-31

> 翻译不用再配 Key 了；一次看多段终于像正常排版；英汉/英英一个开关换着看。

## 新增

- **翻译引擎换成必应（微软 Translator），免 API Key**：走网页接口取令牌后调 `ttranslatev3`，
  国内可直连；「标准 / 正式 / 非正式」三档照旧可用。
  实测同一句：自动「嘿，伙计，怎么样？介意我坐这里吗？」1.77s ／ 正式「您好，朋友，最近怎么样？我可以在这里坐吗？」1.20s ／
  非正式「嘿，伙计，怎么样？我可以坐这里吗？」1.07s。
- **多段按段排版**：一次显示 N 段时，正文每段另起一行、**首行缩进两个字**、段与段之间留白；
  续行回到左边，不会整段缩进。下方译文也按段分组，段间空一行，句序号与原文一一对应。
- **词典「英汉 │ 英英」二态开关**：词条右上角分段控件，点一下就换成英文释义，**内容原地替换**
  （不再在中文下面再堆一块）；点回英汉立刻变回中文，且**不会重新联网**。

## 改进

- 词典徽标同步标注来源：「剑桥 · 英汉」（青色）/「牛津 · 英英」（强调色）。
- 切到英英才请求牛津；牛津结果回来时你已切走，则只写缓存，不会塞进当前这一档。
- 同一词的中英释义各存一份，来回切换都命中缓存。

## 变更

- **DeepL 全部移除**：官方 API 必须带 Key，不填时网页端连续 429，既慢又不可用。
  设置里的 DeepL 勾选与 API Key 输入框一并删除，老配置自动迁移（摘掉 DeepL、必应置顶）。
- 缓存版本升到 3。升级后第一次启动会再清空一次词典与译文缓存；练习记录、生词本、导出成果、历史文章照旧保留。

## 已知问题

- ScienceDaily 的 RSS 偶发「junk after document element」，该源本轮会被跳过，不影响其他来源。
