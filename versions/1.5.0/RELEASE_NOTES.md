# 1.5.0 — 2026-10-30

> 「换一段」点了没反应的老毛病修掉了，顺带能一屏看多段。

## 修复

- **「换一段」点了没反应**：代码调用了并不存在的 `unit_at()`（只有 `demo_unit_at`），
  这个异常在无控制台的打包版里被吞掉，界面表现就是「点了没动静」。补上方法后恢复。
- GUI 冒烟里增加一次真实点按校验（输出 `换一段 0→1`），以后打包能自动守住这类静默失败。

## 新增

- **一次显示段数（1–10，默认 1）**：一屏连续 N 段，按钮变成「标记本 N 段完成」。
- 文章剩余段数不足 N 时，取到末尾为止，不会出现半截。

## 改进

- **进度按实际段数累加**：练习表新增 `para_count`，每日完成数、连续天数、统计、导出统一按它的和计算，
  不再把「一屏 3 段」记成 1 段。老数据库自动补列，不需要手动迁移。
- 已完成的记录不会被后来修改的「一次显示段数」设置改写。
- 多段模式下「换一段」按「起点 + 实际段数」往后取，不会重复显示已看过的段。

## 测试

192 个单元测试（合并/越界/末尾取满/进度求和/老库补列等 12 项）、GUI 冒烟 40 项；exe 13.2 MB 重打包。
