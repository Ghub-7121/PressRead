# 1.0.0 — 2026-10-28

> 首个完整版：从抓一篇文章，到自己译、逐句对答案、导出成果，整条链路能跑通。

## 新增

- **外刊抓取**：内置 14 个来源，`urllib` 实现（gzip、编码探测、主机熔断），RSS 并行拉取。
- **正文抽取**：自建 DOM + 「段落长度投票」选正文容器，过滤图注/导航/样板句，JSON-LD `articleBody` 兜底。
- **阅读与自译**：按句切分；先自己写，再「显示下一句译文」逐句对照；「一次显示全部」会二次确认。
- **查词边栏**：牛津 API → 牛津学习者词典网页 → 备用词典 → 内置离线词表，四级降级，来源如实标注。
- **翻译边栏**：MyMemory 主力（1–2 秒），Google 不可达时自动跳过，LibreTranslate 可自建。
- **本地缓存**：SQLite；单词 30 天、译文 14 天；首页显示缓存命中率，设置页可看统计/清过期/清空。
- **每日任务**：默认 5 段目标、进度点、连续达成天数、练习历史按天回看、译文草稿自动保存。
- **导出**：Markdown + JSON 双份，文件名带自增版本号，旧文件不会被覆盖。
- **离线示例**：`--demo` 不联网也能完整走一遍流程，断网时不至于空白。

## 工程

- PyInstaller 单文件打包（13.1 MB），目标机器无需 Python。
- 四个自检入口：`--smoke`（资源与窗口）、`--selftest`（联网全链路，结果落 `logs/selftest.txt`）、`--demo`、`--practice`。
- 自绘 `CheckRow` / `MiniSlider`：clam 主题的勾选框显示成「×」、滑块带粗红边，一律不用原生控件。

## 测试

145 个单元测试 + GUI 冒烟测试（离线示例 + 预置词条缓存，走完开始页 → 阅读 → 查词 → 揭示 → 完成 → 历史 → 设置）。

## 已知问题

- Google 翻译在国内网络不可达，默认跳过。
- 部分站点有订阅墙，正文可能只返回摘要，长度不足时会提示换一篇。
