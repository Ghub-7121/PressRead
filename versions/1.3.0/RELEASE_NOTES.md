# 1.3.0 — 2026-10-30

> 读到一半想核对上下文、看配图，不用再自己去搜原文了。

## 新增

- **「打开原文 ↗」**：正文标题下方的信息行右端新增按钮，点击用系统默认浏览器打开这篇文章的原网页。
- 历史回看里的旧文章同样能打开：按 `article_id` 回查文章表拿真实链接。
- 浏览器唤起失败时，自动把链接复制到剪贴板兜底。

## 细节

- 只有 `http(s)://` 开头的真实外链才解禁；离线示例（`pressread://demo`）与占位链接保持禁用。
- 按钮最初放在标题行右侧，长标题被裁切后会紧贴文字，改到信息行内「先 pack 右侧按钮、再 pack 左侧文字」才稳定。
